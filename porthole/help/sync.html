Sync Portage Tree

Automatic syncing

Portage keeps a record of every package available to you, the package tree, which needs updating every so often to see new versions. Porthole does this for you in the background: by default it syncs every seven days, then checks for updates. Change how often on the Updates page of Settings, where you can also turn off the check after a sync, or skip syncing while the computer runs on battery.

Hover over the Updates toolbar button to see when the tree was last synced, along with a summary of the latest update check.

Syncing now

Check now in the Update Assistant (or the tray icon's menu) makes a fresh update plan straight away, without a password, but it uses the package tree you already have; it doesn't sync. New versions show up after the next background sync. Syncs use whatever your repositories are set up for in /etc/portage/repos.conf (rsync, git or emerge-webrsync).
