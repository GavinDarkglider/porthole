Sync Portage Tree

Automatic syncing

Portage keeps a record of every package available to you, the package tree, which needs updating every so often to see new versions. Porthole does this for you in the background: by default it syncs every seven days, then checks for updates. Change how often on the Updates page of Settings, where you can also turn off the check after a sync, or skip syncing while the computer runs on battery.

Hover over the Updates toolbar button to see when the tree was last synced, along with a summary of the latest update check.

Syncing now

To sync straight away, press Sync now in the Update Assistant, or choose it from the tray icon's menu. It asks for your password, then syncs and checks for updates in the background; the job window shows how it goes, and the assistant shows the new plan when it is done. Gentoo's mirrors ask that you sync at most once a day, so if the tree was synced within the last day Porthole says so and asks first.

Check now is different: it makes a fresh update plan straight away, without a password, from the package tree you already have.

Syncs use whatever your repositories are set up for in /etc/portage/repos.conf (rsync, git or emerge-webrsync).
