Remove a Package

Basic Removal

To remove a package, select it in the package list and click "Unmerge" in the toolbar (or use Unmerge in its right-click menu, or Package -> Unmerge Package).  Removing needs root, so Porthole asks for your password and hands the removal to its job runner, which runs it in the background; the job window shows it.

In the Updates, Deprecated and Sets views, the packages you tick are removed together, as one job.

Removing a package doesn't remove the packages that were installed because it needed them.  See Removing what is no longer needed below.

If another package complains afterwards about something missing, reinstall the package that complains.

Removing a Specific Version

If you have more than one version of a package installed (in different slots, say) and want to remove just one, right-click that version in the version table of the package's summary tab and choose Unmerge this version.  Advanced Emerge can do the same: choose "unmerge" and the version.

Removing what is no longer needed

To see which packages nothing needs any more, run the custom command "emerge --pretend --depclean".  A pretend run changes nothing, so it runs as you, without a password, in the terminal.  Read its list, and its warnings, carefully.

When you are sure, run the custom command "emerge --depclean".  Porthole asks for your password and the job runner removes them.  To stop it part way, press Kill in the job window and choose Stop; what was already removed stays removed.
