Custom commands

Porthole, Run Custom Command runs any command line in Porthole's terminal window, where its output is coloured and its warnings collected like emerge's. Use it for things Porthole has no button for: eselect, equery, emerge --info, scripts of your own.

The dialog

Type the command, or pick one from the list: first your saved commands (set in Settings, Porthole, Commands), then the ones you ran recently. Press Execute.

What happens to the command

  • Emerge commands that install, update, remove or sync are handled the way Porthole always handles those: installs go through the install queue to be planned and checked, removals and syncs become jobs for the runner.
  • Everything else runs as you, in the terminal, without administrator rights. Pretend runs and --info are like this too.
  • While Porthole is unlocked, Porthole shows you the exact command and asks how to run it: Run as you, or Run as root. As root it runs as a job in the job window, and it asks for the password again, even though Porthole is unlocked: Porthole checks everything else it runs as root, but it can't check an arbitrary command for you, so you confirm it yourself.
A command run as root can change anything. Read it before confirming. It runs without a terminal to type into, so commands that ask questions won't get answers; give them the options to run on their own.
