Finding packages

Searching

Type part of a package's name in the search box and press Enter. The view switches to Search Results: every package whose name contains what you typed, in any category. Case doesn't matter. Each search is kept in the list on the left while Porthole runs, so you can go back to earlier ones.

Tick Descriptions next to the search box to search the package descriptions too (to find "a PDF viewer" without knowing its name). The first such search reads every description, which takes a little while; later ones are quick.

The search term is a pattern: ^vim finds names starting with vim, office|writer either word. A + is taken as itself, so gtk+ works as you would expect.

Browsing

In All Packages or Installed Packages, choose a category on the left to list its packages. Typing while a list has the focus jumps to the first entry starting with what you type. Click a column heading to sort by it.

What the columns mean

  • Installed: the version on this computer, if any.
  • Recommended: the version Portage would install. In brackets: no version can be installed as your settings stand (usually the package is only in testing), so this is the newest one; masked: every version is masked. In Updates Available, the version the update plan installs, in brackets if it is held back.
  • Download Size: what installing it would download.

Which columns show is set in Settings, Porthole, Package list.
