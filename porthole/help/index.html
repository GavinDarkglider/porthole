About Porthole

Porthole is a graphical front end for Portage, Gentoo's package manager. You can browse and search every package, see what is installed and why, and install, update and remove software without typing emerge commands. It also looks after keeping the computer up to date: it checks for updates on a schedule, works out the problems Gentoo updates often run into (settings to change, packages blocking each other, rebuilds) before anything is built, and shows you a plan to approve.

What Porthole does for you

  • Browsing and searching: all packages by category, what is installed, what has updates, package sets, and a search over names and descriptions. See The main window.
  • Installing with a plan: packages you choose go into a queue; Porthole works out everything they need together, checks it, and shows you the plan before installing. See Installing packages.
  • Updates that are worked out first: the setting changes an update needs are proposed and checked with Portage before you see them; what can't be updated yet is explained, with your options. See Updates.
  • Building when it suits you: approved updates can wait for a time nobody is using the computer, pause if someone comes back, and run by themselves if you choose. See How updates run.
  • Settings in plain words: USE flags by what they do, licences, the profile, repositories and binary packages, each change previewed before it is made. Porthole never rewrites your make.conf. See Settings.

How Porthole is put together

Porthole is four parts that work together:

PartWhat it doesRuns as
Porthole (this window) Browsing, searching, choosing, reviewing plans, settings. you
The resolver Works out plans: what to build, which setting changes are needed, what is held back and why. Every change it proposes is checked with Portage before it is shown. you (and root, to check a plan again before carrying it out)
The runner Carries out every change: installs, updates, removals, syncs. Jobs keep running when you close Porthole; the job window follows them. root
The tray icon Tells you when updates are waiting, shows how a job is going, and reminds you when updates have waited a while. you

Looking needs no password. Only changing something does: the change is handed to the runner through porthole-update-service, which checks what it is asked to do before doing it. You can unlock Porthole for a while, so that you type the password once instead of for every change.

Where to start

  • The first time Porthole starts, it asks how updates should run. If you aren't sure, choose Tell me, I start updates myself; you can change it later in Settings, Updates.
  • To install something, search for it, select it and press Emerge: Installing packages.
  • To update, press Updates on the toolbar: Updates.
