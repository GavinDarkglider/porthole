Unlock and administrator rights

Porthole runs as you. Looking at packages, searching, working out plans and checking for updates need no password. Changing the system does: installing, updating, removing, syncing, and settings for the whole computer. Each such change is handed to Porthole's runner through porthole-update-service, run as root with sudo (or, if sudo isn't allowed, pkexec). Your sudo rules decide whether a password is asked.

Unlocking

To avoid typing the password for every change, press Unlock on the toolbar (or in Updates) and type it once. Until the time is up, changes go through without asking. The button shows the time left and reads Lock; press it to lock again straight away. How long an unlock lasts (15 minutes, an hour, or until Porthole closes) is your own setting, in Settings, Porthole, General.

What unlocking also gives you

  • Check now works out the plan as root, which also sees programs still using old libraries, so their rebuild is in the plan.
  • The Sets view shows @preserved-rebuild as it is now.
  • Custom commands can run as root (each one still asks for the password, see below).

How it works, and what it guards against

Unlocking starts porthole-update-service session as root for this Porthole only. It talks to Porthole through a private pipe, with no network socket and no file anyone else could reach, and runs only the service's own checked commands, the same ones Porthole uses when locked. It stops when you lock, when the time is up, or when Porthole closes.

  • While unlocked, no other program, not even one running as you, can attach to Porthole or reach that pipe.
  • A custom command as root always asks for the password again, even while unlocked: a command line is the one thing the service can't check for you.
  • Everything the service is asked to do is checked as root: which files may be changed, which emerge options are allowed, that names are real package names. A plan you approved is worked out again as root before anything is built.
If Porthole runs from a folder your account can change (a copy of its source, for example), a bar at the top of the window says so: anything it runs as root comes from there, so any program you run could change what root runs. That is fine for working on Porthole; for everyday use, install it.
